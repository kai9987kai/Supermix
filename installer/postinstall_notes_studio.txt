Supermix Studio installs a curated core model set and the shared Qwen base model directly with the app. Additional supported models can be added through the model store.

Notes:
- The first time you open a model, the app may extract that zip into its local runtime cache before loading it.
- Auto mode routes each prompt to the most appropriate bundled model instead of pinning one model for the whole session.
- Image-capable models render images directly inside the chat thread.
- The app stores generated images and extracted working copies under its runtime state directory in your user profile.
- SupermixRouteStudy.exe is installed beside the desktop app. It exports and audits prompt-free experiment protocol drafts; it cannot assign or execute routes, write evidence, estimate policy value, or activate promotion.
- SupermixStudioRuntimeManifest.json and the release SHA-256 file describe the packaged runtime contract and artifact integrity.
