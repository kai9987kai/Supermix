MiMoMix v53 — Dem-Lab Observatory

A single-file, local-first bench for the Supermix v53 hybrid: MiMo-style hybrid attention and sparse MoE, multi-token-prediction speculative decoding, the v52 verified-recursion budget ladder, and the Dem-Lab statistics that watch all of it. Every panel runs the same algorithm as the Python implementation in source/mimomix_*.py. Nothing here talks to a network, and settings persist in this browser only.

Live model — measured

This is the only panel on this page that measures a model. Every other panel is a slider-driven simulation of the v53 algorithms. This one reads a running v56 reasoner over /api/status and /api/telemetry, so it is blank unless this page is served by source/mimomix_reasoner_web_app.py.

Hybrid attention & KV cache

Local sliding-window layers interleaved with global layers. Only global layers keep an unbounded cache — that asymmetry is the entire memory story.

Aux-loss-free MoE balancing

Experts are selected by score + bias but weighted by score alone, so the balancer never distorts the forward value. The bias moves by bi += γ·sign(mean load − loadi).

MTP self-speculative decoding

The trunk emits one exact token; the MTP depths speculate the next few. A drafted token is kept only if it equals the trunk's own argmax, so the output is identical to greedy decoding — the draft buys forwards, never correctness.

Acceptance length is tokens committed per trunk forward. Plain greedy scores exactly 1.00. The theoretical value for i.i.d. acceptance probability p over d depths is (1−pd+1)/(1−p).

Progressive thinking ladder

Plan a floor and ceiling from observable cues, then climb the budget ladder. An early exit needs the verifier to stand down and confidence/entropy targets met and the ordered top-k to agree with the previous budget.

Entropy & randomness battery

Shannon and min-entropy plus a chi-square uniformity test with an exact regularised-incomplete-gamma p-value, a monobit test and a runs test — the same battery as mimomix_observatory.py.

Policy ecosystem (replicator dynamics)

Controller policies compete on fidelity minus cost. Discrete replicator dynamics: xi' = xi fi / ⟨f⟩. Deterministic, mass-preserving, and it converges on the policy that actually pays.

What this is not. Every panel below “Live model” is a faithful re-implementation of the v53 algorithms, driven by sliders and a seeded PRNG rather than by a trained checkpoint. They show how the mechanisms behave under parameters you choose. They are not measurements of a model, they are not benchmark results, and no number in them is evidence that any checkpoint reasons well.

What is measured. Only the “Live model” panel, and only when this page is served by source/mimomix_reasoner_web_app.py with a real supermix-v56-reasoner-checkpoint-v1 loaded. Its numbers come from that checkpoint's own forward passes. They describe one synthetic 4-step modular-arithmetic task and nothing else — not language, not general reasoning, and not transfer to any other workload. For the full evidence chain run pytest test_mimomix_*.py and python source/run_v56_promotion_gate.py.
